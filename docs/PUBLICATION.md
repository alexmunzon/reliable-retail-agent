# Publication snapshot

This is a clean offline delivery snapshot, created separately from the private development checkout. It preserves the final demo, relevant gate/controller code, selected synthetic tests, public author source/artifacts and zero-cost analysis. Private credentials, provider transcripts, account ledgers, machine paths, and prior development Git history are excluded.

`native/project_budget.py` is intentionally reduced to the exact typed `BudgetStop` exception used by offline controller contracts. It contains no account authorizations, budgeting implementation, provider adapter, or paid execution capability. All original local development files and frozen research evidence remain unchanged in the original checkout. Historical local model experiments are not evidence for the scores published here.

The demo and current gate remain **unevaluated** against real models. Offline tests establish code behavior under specified fixtures; they do not estimate model performance. Later author trajectory recomputation establishes what those released records contain; it does not establish original historical model availability or re-execute provider calls.

No public hosting was performed. The app is designed for a loopback Python server; a static GitHub page cannot execute its backend.
